# UnrealSystemLab

用可交互的学习单元理解游戏系统，把原理、引擎机制和实际开发连接起来。

项目面向会打开 UE、能运行基础示例，希望进一步建立系统认识的游戏开发者。先操作场景、看见过程、修改条件，再进入公式、代码和源码路径，最后完成一个变化后的任务。

## 当前进度

更新于 2026-10-26。当前已完成产品定位、实验指导方针、实验模板，以及“单墙碰撞实验：Sweep 与滑动”的实现计划。学习单元与文档按主题和功能命名。

UE 工程已由第三人称 C++ 模板初始化。单墙碰撞实验已存在 Step 1 的实验 Actor 源码、蓝图和地图，当前状态为待验证；最新源码的构建、场景配置和 PIE 显示由作者按手动文档执行与确认。Sweep 与滑动等后续 Step 尚未实现，打包和学习者试用未完成。

开发基线：UE 5.7.4，目标平台 Windows。本机已核对引擎版本和相关源码，当前构建与运行结果仍待作者手动确认。

## 作者与 AI 的协作

作者确定学习目标、关键模型、机制解释和验收，逐步形成独立修改与诊断能力。AI 可以协助原型、局部代码、可视化、数据整理和文档；每次改动都应当可审阅、可验证。

AI 只进行 Coding、源码层面人工审阅和文档编写。配置、构建、运行及测试由作者手动执行并确认；AI 不通过 Skill、脚本或编辑器工具自行完成这些操作。

一个发布周期同时检查：读者是否学会、作品是否可独立使用、作者是否掌握新的关键机制。已掌握的部分可以直接复用。

协作细则见 [AGENTS.md](AGENTS.md)。
