# UnrealSystemLab

用可交互的学习单元理解游戏系统，把原理、引擎机制和实际开发连接起来。

项目面向会打开 UE、能运行基础示例，希望进一步建立系统认识的游戏开发者。先操作场景、看见过程、修改条件，再进入公式、代码和源码路径，最后完成一个变化后的任务。

## 当前进度

更新于 2026-10-23。当前已完成产品定位、首卷课程与排期、实验指导方针、第一课设计和起步任务拆分。

UE 工程与可运行 Demo 尚未创建，尚未完成编译、打包或学习者试用。下面的场景与功能均为计划，不代表已经可运行。

开发基线：UE 5.7.4，目标平台 Windows。本机已核对引擎版本和相关源码，开发工具链仍需验证。

## 作者与 AI 的协作

作者确定学习目标、关键模型、机制解释和验收，逐步形成独立修改与诊断能力。AI 可以协助原型、局部代码、可视化、数据整理和文档；每次改动都应当可审阅、可验证。

一个发布周期同时检查：读者是否学会、作品是否可独立使用、作者是否掌握新的关键机制。已掌握的部分可以直接复用。

协作细则见 [AGENTS.md](AGENTS.md)。
